Fully Connected Layer
Vektor hasil Global Average Pooling (1.280 nilai) masuk ke satu lapisan Dense berisi 128 neuron (aktivasi ReLU) dengan Dropout saat pelatihan, lalu ke lapisan output Softmax. Setiap neuron pada layer ini terhubung ke semua elemen vektor untuk mempelajari kombinasi fitur pembeda kelas penyakit.

PERHITUNGAN KLASIFIKASI DENSE & SOFTMAX
zk = ∑ (Xi x Wi,k) + bk  ⟹  P(yk) = ezk / ∑ ezj
Lapisan Dense mengubah 1.280 fitur GAP menjadi 4 nilai logit mentah (z_k), kemudian fungsi Softmax menormalisasikan logit menjadi persentase probabilitas.
💡 Cara Menggunakan Rumus Ini (Rincian Hasil Perhitungan):
Langkah 1 — Hitung Logit Mentah zk: Kalikan 1.280 nilai fitur GAP (X) dengan matriks bobot kelas (W), lalu tambahkan bias (b).
  • Data Asli Model: z1 (Bercak Ungu) = (X₁W₁ + X₂W₂ + ... + X₁₂₈₀W₁₂₈₀) + b₁ = +3.825
Langkah 2 — Ubah ke Eksponensial ezk: Hitung nilai eksponensial (e = 2.71828) untuk masing-masing dari 4 logit.
  • Data Asli Model: e+3.825 = 45.83272 | Total Σ ez seluruh 4 kelas = 48.08032
Langkah 3 — Hitung Probabilitas Softmax: Bagi nilai ez kelas tersebut dengan Total Σ ez, lalu kalikan 100%.
  • Hasil Akhir Prediksi: P(Bercak Ungu) = (45.83272 ÷ 48.08032) x 100% = 95.33%
