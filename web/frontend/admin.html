Langkah 1 — Unggah Dataset (cukup sekali)
Siapkan satu file .zip berisi folder per kelas penyakit, contoh: dataset.zip → Trotol/*.jpg, Moler/*.jpg. Nama folder otomatis menjadi nama kelas — tidak perlu diketik ulang di mana pun. Upload berikutnya akan menggantikan dataset lama (biarkan sistem mempelajari versi terbaru). Foto boleh diunggah apa adanya langsung dari kamera/HP (resolusi tinggi) — server akan mengompres & mengecilkan gambar secara otomatis sebelum training, jadi tidak perlu dikompres manual dulu.
